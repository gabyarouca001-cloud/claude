# Awesome Design (DESIGN.md)

Coleção da VoltAgent (`awesome-design-md`, licença MIT em `LICENSE`) com 74 arquivos `DESIGN.md`, um por marca,
em `design-md/<marca>/DESIGN.md`.

## Como usar
1. Listar as marcas: `ls .claude/skills/awesome-design/design-md/`
2. Ler **só** o `DESIGN.md` da marca pedida (tema visual, paleta e papéis das cores, tipografia, componentes,
   espaçamento, profundidade, "faça / não faça", comportamento responsivo e guia de prompt).
3. Gerar a interface seguindo esse arquivo. Se for para um projeto novo, copiar o arquivo escolhido para a raiz
   do projeto como `DESIGN.md` e dizer ao Claude para segui-lo.
4. Usar como **ponto de partida**: adaptar à marca da editora, sem copiar logos nem textos da marca de referência.

## Atenção neste repositório
O padrão visual dos vídeos DEEP (amarelo manteiga `#FCEDC0`, Playfair Display + Inter) está no `CLAUDE.md` e
**prevalece** sobre qualquer DESIGN.md de terceiros.
